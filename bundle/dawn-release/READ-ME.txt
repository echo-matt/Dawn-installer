DAWN PLAYER INSTALLER

1. Extract the entire release ZIP into a new folder (for example, Downloads).
2. Close Destiny 2.
3. Double-click Install-Dawn.cmd.
4. Enter your existing game folder: the folder containing destiny2.exe.

Requires Destiny 2 version 86657.20.08.23.1800.d2_rc and Windows PowerShell 5.1
or newer. No compiler, Python, separate Lua installation, or source code needed.
This is an update for an existing game installation; the game is not included.

EVERY INSTALLATION STARTS A FRESH SAVE, including reinstalling the same release.
The installer replaces both steam_api64.dll copies and the two Dawn runtime
folders as one release. It installs the shipped settings, scripts, vendor rules,
and event presets exactly as packaged. Existing progress, settings, identity,
event choices, and custom scripts are not carried into the new installation.
The game creates a new player database from the release defaults on first launch.

Your old Sunrise/Restoration folders stay intact. Previous Dawn folders and DLLs
are backed up under <game>\.dawn\release-backups. Nothing launches automatically.
Caches are generated by the game, so first launch can take longer.

The installer sets Windowed Fullscreen as the launch default for the Windows
user running it. Your resolution, graphics quality, and key bindings are kept.
You can select another mode later in the game's Video settings. This changes
the shared Bungie/DestinyPC preference file, so other Destiny 2 installations
under the same Windows user also see this mode. DLL-only updates do not set it.

No profile selection or special new-save flag is needed. Multiple old Sunrise
or Restoration folders do not block installation; their profiles are ignored.
To run directly from PowerShell:
  .\Install-Dawn.ps1 -GameRoot 'C:\Your Game'

Preview without changing the game:
  .\Install-Dawn.ps1 -GameRoot 'C:\Your Game' -WhatIf

Restore the most recent installation (close the game first):
  .\Install-Dawn.ps1 -GameRoot 'C:\Your Game' -Restore

To restore a specific backup, also pass -BackupPath followed by its full path.
Rollback keeps displaced Dawn files, including progress made since installation,
in that backup's after-restore folder. Keep these files if you need that progress.
Do not delete a backup while installation or recovery is in progress.
Rollback also restores the original display preferences (or removes the file
if it did not exist). Newer preferences are retained under after-restore.
Run rollback from the same Windows user profile used for installation.

Only run release bundles from a trusted publisher. The manifest checks that its
payload matches; it is not a digital signature proving who published the bundle.
